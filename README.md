# Morse translator
## Pre-requisites:
You must python 3.x installed on your system
In a virtual environment or such, type:
`pip install -r requirements.txt` 
or on Mac/Linux:
`pip3 install -r requirements.txt`

## Help Manual:
See the help manual by running:
`python main.py --help`
or on Mac/Linux:
`python3 main.py --help`
